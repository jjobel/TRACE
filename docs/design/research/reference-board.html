1. MoTeC i2 Pro: the layout to stay close to

These are real i2 Pro 1.1.4 screens showing the workspace that ships with Assetto Corsa Competizione, published in a Coach Dave Academy tutorial. They are the screens most sim racers, and many club racers, already know.

4. The other professional tools

MoTeC is not alone in this layout. Across seven tools the same parts keep turning up, which is what makes them the standard an engineer expects.

Found in three or more of them

  • A command area across the top and tabbed pages.
  • A horizontal lap strip, and a list of laps on the left.
  • A legend that shows the live cursor value beside each trace.
  • Black plot areas in the team-grade tools; white by default in AiM and Racelogic.
  • Overlay against distance, with the fastest lap as the default reference.
  • The time difference between two laps as its own trace under the main chart.
  • One cursor shared by the chart, the track map and video.
  • Single keys for next lap, previous lap and fastest lap.
  • The words "Workbook" (ATLAS, Cosworth, Bosch, MoTeC) and "Worksheet" (Cosworth, Bosch, MoTeC).

Marelli WinTAX4 follows the same pattern but publishes no screenshots outside PDF manuals. The sign of the time difference is not uniform between tools, so TRACE has to state its own.

5. How other open-source tools handled switching

Lessons that apply to TRACE

  • Offer the familiar layout and keys as a named, maintained set. Blender did this with one "Industry Compatible" keymap; Inkscape's Illustrator keymap went stale and Krita's Photoshop scheme once broke on a typo, so the set needs a test.
  • Where things sit and what they are called carry most of the familiarity.
  • A control that looks the same must behave the same. Half-copies annoy switchers more than honest differences.
  • Reading the user's old files decides switching more than looks do. TRACE's MoTeC .ld Adapter matters as much as this design.
  • Publish a "Coming from MoTeC" page listing every deliberate difference.
  • Use our own name, icons and artwork. Menu structure and shortcuts are generally treated as functional (Lotus v. Borland; Apple v. Microsoft); icons, names and a distinctive overall look are not. This is not legal advice.

6. Where the style comes from

The first design was rejected for looking like a stock dashboard. The three directions take their style from motorsport and instrument sources instead.

Printed sheet reference for direction B: the FIA race history chart, white paper with a black title band and ruled lap blocks (FIA PDF). The official colour key is in the Help panel of the F1 Academy live timing page; it comes from the rights holder, not from an FIA regulation.

8. Open points

  • Words that are not in the glossary yet: Workbook, Worksheet, Component; Main, Overlay and Reference lap; and what to call the time difference trace (MoTeC "Variance", ATLAS "Time Diff", AiM "Time Compare"). The mockups use MoTeC's words.
  • Sign of the time difference. The mockups show a positive value when the Overlay lap is behind the Main lap.
  • MoTeC's sections versus TRACE's Sectors. i2 reports on user-defined track sections (Turn 1, Straight 1 to 2). The mockups show Sectors only, as the glossary defines them.
  • "MoTeC i2" as the name of the key set uses MoTeC's trade mark and belongs in the trade mark clearance already on the list.
  • An existing open-source project, Track Data Analysis (MIT, Python and Qt), already reads MoTeC, AiM and Racelogic files with an i2-like layout. Its author notes that i2 is "almost" sharp on high-resolution screens and Windows only.
  • Not confirmed: the current i2 hot-key list (taken from an older third-party guide), and whether any FIA regulation defines the timing colours.
