TRACE design system: screens

One system in two themes: the Timing screen (dark) and the Run sheet (light). Layout, type, spacing and rules are identical in both; only the colour tokens change. All data is made up. The rules behind these screens are in design-system.md; the research is on the reference board.

Dark themeLight theme

Timing screen (dark theme)

Library

The start screen. Every imported Log with its date, Venue, Course, Session, Vehicle and Source, or a plain note where the file did not supply one. Import by button or by dropping a file on the window. The version is in the status bar.

Log and Channel plot (phase 1)

The Log view and the Channel plot in one window, laid out like MoTeC i2. Data pane with Outings and the lap table; the best Lap, the Out-lap, the In-lap and a Deleted lap are each marked. Views that arrive in later phases are greyed.

Control lines

For a Log with position data but no Control line. Click the path to place the Start/Finish line and optional intermediate lines; the Laps they give are shown at once. The lines are saved with the Course.

Dialogs and messages

Confirming a delete, a file that cannot be imported, a Log in which Laps cannot be found, and the bar that offers Control line placement.

Later phases: overlay, Variance and track map

The same window once lap overlays, the time difference trace and the track map exist. Nothing moves; the greyed controls come alive.
