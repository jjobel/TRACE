# License TRACE under GPL-3.0-or-later

TRACE is a community-built desktop application. It is licensed under GPL-3.0-or-later, so that anyone who distributes a modified TRACE must publish their changes and nobody can ship a closed fork of the app. The cost is that TRACE code cannot be embedded in proprietary products, and every dependency must be GPL-compatible.

## Considered Options

- **MIT**: maximally permissive and easiest for adoption, but allows closed forks of the application.
- **GPL-3.0-or-later** (chosen): copyleft for the whole application; "or later" lets the project move to a future GPL version without contacting every contributor.
