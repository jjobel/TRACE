# License TRACE under GPL-3.0-or-later

TRACE is meant to be a community-built desktop application in the mould of GIMP and Inkscape, both GPL. We license it under GPL-3.0-or-later, replacing the MIT license from the initial commit, so that anyone who distributes a modified TRACE must publish their changes and nobody can ship a closed fork of the app. The cost is that companies wanting to embed TRACE code in proprietary products cannot, and every dependency must be GPL-compatible.

## Considered Options

- **MIT** (the initial license): maximally permissive and easiest for adoption, but allows closed commercial forks of the application.
- **GPL-3.0-or-later** (chosen): copyleft for the whole application; "or later" lets the project move to a future GPL version without contacting every contributor.
